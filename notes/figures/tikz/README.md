# Reviewed vector exports

These PDFs are generated from `../../../figures_tikz/src/` by running:

```sh
./figures_tikz/build_and_check.sh
```

The build copies a PDF here only after verifying that it is one page, contains
no raster image objects, uses no Type 3 fonts, and embeds every font.  Do not
edit these exports directly.  The authoritative source, recovered coordinate
data, provenance notes, and QA tooling live in `figures_tikz/`.

The Holt--Laury export is a subset of the original article's Table 3. Its last
two columns are distributions over total safe choices, not decision-by-decision
rates of choosing Option B.
