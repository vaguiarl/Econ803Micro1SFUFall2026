# Problem sets

Each released set has two deliberately different parts.

1. **Part I: By hand.** Short, tractable problems intended for the board or a seminar table. Each problem isolates one economic mechanism and is solvable without code.
2. **Part II: Verified scale-up.** A guided extension of a named Part I seed. Students use Codex with Python, Lean, or both, but must state the scaling step, inspect the generated work, run the required checks, and interpret the result economically.

The distinction is about the intellectual job, not difficulty alone. Part I establishes the benchmark students should understand without automation. Part II changes one dimension at a time - more goods, more observations, weaker assumptions, or a formal theorem - so that computation does not obscure the economics.

The [problem-set standard](PROBLEM_SET_STANDARD.md) defines the required bridge and submission contract. Released student packets appear below in teaching order.

The [teaching-order pairing plan](PAIRING_PLAN.md) maps the book's stable problem IDs into the same hand-to-scale progression for all thirteen meetings. It is a release roadmap, not a schedule of due dates.
