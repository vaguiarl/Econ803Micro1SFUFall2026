# Problem Set 1: From Two-Good Demand to Verified General Demand

This is the first release using the two-part ECON 803 format.

- [Student handout (PDF)](PS01_Consumer_Demand.pdf)
- [Authoritative editable LyX source](PS01_Consumer_Demand.lyx)
- [Lean starting file](Starter.lean)

Part I is designed for approximately 40 minutes of board work. Part II extends the same ideas to five goods and arbitrary finite dimension. Students use Codex for implementation support and Lean for the formal scaling statement, while retaining responsibility for assumptions and interpretation.

The packet is questions only. Instructor solutions are maintained in the private course repository.
